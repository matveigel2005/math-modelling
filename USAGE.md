# Инструкция по визуализации решения

Для построения анимации распределения температуры в L-образной области
используйте скрипт `make_animation.py`. Он автоматически запускает
сервер (если нужно), отправляет задачу, дожидается результата и создаёт
видеофайл.

## Запуск

```bash
python3 make_animation.py
